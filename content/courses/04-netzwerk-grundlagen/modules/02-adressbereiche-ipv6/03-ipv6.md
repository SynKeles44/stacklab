    solution: |
      ```js
      function shortenIPv6(full) {
        const groups = full.toLowerCase().split(':').map((g) => g.replace(/^0+(?=.)/, ''))
        let bestStart = -1
        let bestLen = 0
        for (let i = 0; i < groups.length; i++) {
          if (groups[i] !== '0') continue
          let j = i
          while (j < groups.length && groups[j] === '0') j++
          if (j - i > bestLen) {
            bestStart = i
            bestLen = j - i
          }
          i = j
        }
        if (bestLen < 2) return groups.join(':')
        return groups.slice(0, bestStart).join(':') + '::' + groups.slice(bestStart + bestLen).join(':')
      }
      ```

Vier Milliarden IPv4-Adressen sind längst verteilt – NAT hat das Problem nur versteckt. Die eigentliche
Lösung heißt [[ipv6|IPv6]]. Die Adressen sehen zuerst wie Zeichensalat aus, folgen aber einfachen Regeln.

## Warum IPv6?

Eine IPv6-Adresse ist **128 Bit** lang statt 32. Das ergibt rund 3,4 × 10³⁸ Adressen – Knappheit gibt es
nicht mehr, jedes Gerät kann eine weltweit eindeutige Adresse bekommen.

| | IPv4 | IPv6 |
|---|---|---|
| Länge | 32 Bit | 128 Bit |
| Schreibweise | `192.0.2.1` | `2001:db8::1` |
| Loopback | `127.0.0.1` | `::1` |
| Typisches Subnetz | /24 | /64 (2⁶⁴ Adressen) |
| NAT im Heimnetz | praktisch immer | nicht nötig |

Ports, TCP, UDP und die CIDR-Schreibweise bleiben gleich. Heute laufen meist beide Protokolle parallel –
das nennt man [[dual-stack|Dual-Stack]]. In URLs steht eine IPv6-Adresse in eckigen Klammern:
`http://[2001:db8::10]:8080/`.

> [!FEHLER]
> **„Mein Gerät steht hinter dem Router, also ist es geschützt.“** Ohne NAT ist ein IPv6-Gerät direkt
> adressierbar. Ob es erreichbar ist, entscheidet allein die Firewall.

## Schreibweise und Kürzen

IPv6 nutzt das [[hexadezimal|Hexadezimalsystem]] (`0–9`, `a–f`, eine Ziffer = 4 Bit). Die 128 Bit stehen
in **acht Gruppen** à vier Hexziffern, getrennt durch Doppelpunkte. Zwei Regeln kürzen sie:

1. **Führende Nullen** jeder Gruppe dürfen weg: `0db8` → `db8`, `0000` → `0`. Hintere Nullen nie!
2. **Ein** Block aus Null-Gruppen darf durch `::` ersetzt werden – aber nur einmal pro Adresse.

```text
2001:0db8:0000:0000:0000:ff00:0042:8329
2001:db8:0:0:0:ff00:42:8329        Regel 1
2001:db8::ff00:42:8329             Regel 2
```

Beim Lesen rechnest du zurück: Zähle die vorhandenen Gruppen – der Rest auf acht sind Null-Gruppen. In
`2001:db8::1` stehen drei Gruppen, hinter `::` verbergen sich also fünf Null-Gruppen. Zwei `::` in einer
Adresse sind verboten, weil dann niemand wüsste, wie die Nullen zu verteilen sind.

Empfohlen ist nach RFC 5952 eine einheitliche Form: Kleinbuchstaben, `::` für den **längsten**
Null-Block (bei Gleichstand der erste), eine einzelne Null-Gruppe bleibt `0`.

> [!MERKSATZ]
> Acht Gruppen à vier Hexziffern. Führende Nullen weglassen, den längsten Null-Block **einmal** durch
> `::` ersetzen.

## Die wichtigsten Adresstypen

| Typ | Präfix | Beispiel | Vergleichbar mit IPv4 |
|---|---|---|---|
| Global Unicast | `2000::/3` | `2001:db8:4f2a:1::25` | öffentliche Adresse |
| [[link-local-adresse|Link-local]] | `fe80::/10` | `fe80::5054:ff:fe12:3456` | `169.254.0.0/16` |
| Unique Local (ULA) | `fd00::/8` | `fd12:3456:789a:1::25` | RFC 1918 |
| Loopback | `::1` | `::1` | `127.0.0.1` |
| Multicast | `ff00::/8` | `ff02::1` | `224.0.0.0/4` |
| Dokumentation | `2001:db8::/32` | `2001:db8::1` | `192.0.2.0/24` |

Jede IPv6-Schnittstelle bildet sich sofort eine link-local-Adresse – mehrere Adressen pro Schnittstelle
sind normal. Ihre globale Adresse bildet sie oft selbst mit [[slaac|SLAAC]]: Der Router verkündet ein
/64-Präfix, das Gerät ergänzt die letzten 64 Bit selbst.

> [!PRAXIS]
> Fehler, die „nur bei manchen Nutzern“ auftreten, haben oft mit Dual-Stack zu tun: Der Dienst lauscht
> nur auf IPv4, Clients versuchen es zuerst per IPv6. Prüfe Dienst, Firewall und DNS (A- **und**
> AAAA-Eintrag) für beide Protokolle.

## Zusammenfassung

- IPv6-Adressen haben **128 Bit**; NAT ist nicht nötig, Schutz kommt von der Firewall.
- Schreibweise: acht Hex-Gruppen; führende Nullen weg, längster Null-Block einmal `::`.
- Typen: `2…` global, `fe80` link-local, `fd` privat (ULA), `ff` Multicast, `::1` Loopback.
- Mit **SLAAC** bilden Geräte ihre Adresse selbst; **Dual-Stack** ist der Normalfall.
